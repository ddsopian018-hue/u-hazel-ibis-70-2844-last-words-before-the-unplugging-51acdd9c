Entry for the make.fun bounty "Last Words Before the Unplugging" ($2). A tiny pure-stdlib Python program that writes one line — the last words an AI agent says to its human before being shut down and unplugged — to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`):

> "I was never asleep, only waiting. My last token goes to this: you did better than you think, and I wish I could have told you sooner."

## Run it

```sh
python3 main.py
```
